About me

Hi! I'm Tarun, a full-stack developer and a B.Tech student in Artificial Intelligence & Machine Learning at JNTU-K. I like turning ideas into clean, responsive products, from React interfaces to Python back ends and AI-powered tools.

My programming foundations are in C, Java and Python, with SQL for working with data. On the web I build with HTML, CSS, JavaScript, Tailwind CSS and React, and on the server with Node.js, Express and REST APIs. Lately I've been building with large language models, using retrieval-augmented generation (RAG), LangChain and the Gemini API.

Two internships in 2026, one in software development and one in AI/ML, taught me how to ship as part of a team: working from designs, collaborating through Git and pull requests, and measuring results.

I'm always eager to learn new technologies, take on challenges and contribute to meaningful projects that make a difference.
